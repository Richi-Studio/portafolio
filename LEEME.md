# Portafolio Studio By Richi (versión 1 · borrador)

Sitio de una sola página con scroll por áreas de trabajo. No modifica el sitio publicado en `Uni 2026-2\Diseño Web\Portafolio`.

## Ver en el computador
`node serve.js` y abrir http://localhost:5178 (o usar la vista previa de Claude).

## Dónde se cambia cada cosa
| Qué | Archivo |
|---|---|
| Proyectos, textos, orden, contacto | `data/proyectos.js` (fuente única) |
| Lista de imágenes (id → archivo) | `data/imagenes.js` (se regenera desde `/img`) |
| Colores, tipografías, espaciado | `css/estilos.css` (variables al inicio) |
| Imágenes optimizadas | `img/` (webp, 700–1400 px) |

## Identidad (del Brand Book de Studio By Richi)
Negro `#000`, blanco `#FFF`, grafito `#1C1C1C`, humo `#6B6B6B`, niebla `#EDEDED`, Amarillo Chispa `#FFD43B`. Poppins para texto y Boogaloo para titulares.
